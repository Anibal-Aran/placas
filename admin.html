Configurar el permiso de GitHub

Una sola vez por equipo. Es un permiso que sólo sirve para publicar esta app.

  1. Con la cuenta Anibal-Aran, entrá a GitHub › Fine-grained tokens › Generate new token.
  2. Nombre: Placas admin. Vencimiento: el que prefieras (por ejemplo, un año).
  3. Repository access: Only select repositories › placas-formas-de-pago.
  4. Permissions › Repository permissions › Contents: Read and write. Nada más.
  5. Generate token, copialo y pegalo acá abajo.

Queda guardado sólo en este navegador, cifrado con tu clave de administrador.
